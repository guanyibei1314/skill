# 原图视觉相似性验收

验收目标不是“动漫风格大致类似”，而是**《失落的風鈴》开发板的完整艺术构成**。

## A 类：结构硬约束（缺一不可）

- [ ] 单张纵向成图，接近 992×1586 比例
- [ ] 上方深蓝大字手写片名，右侧精绘场景横幅
- [ ] A 区有主角完整全身正面、侧面、3/4 视图，不只是头像
- [ ] 有四种表情、动作研究、配件局部、粉彩色板和边注
- [ ] 第二角色若存在，须包含三视图、表情和姿态，不能被挤没
- [ ] B 区严格 01–08，三排分别为 3+3+2，末排两个宽格
- [ ] 每格有朱红细边、上彩色主帧、下小幅石墨铅笔草稿及说明
- [ ] 手写拍摄笔记、蓝/红运镜箭头与镜头技术标记清晰存在

## B 类：画工和气氛

- [ ] 泛黄、带细微纹理的暖白水彩纸，不是纯白/纯黑界面
- [ ] 精细线稿、柔和人物体积、自然比例、原创 2D 动漫人物
- [ ] 细腻夏日空气感、柔光、水彩晕染、丰富且温和的场景深度
- [ ] 角色设定和彩色关键帧及小灰稿笔触协调、信息密度足够
- [ ] 角色脸型、发型、服装、动物毛色和关键道具跨区一致
- [ ] 分镜有建立—发现—互动—转折—收束的情绪节奏，终幕有空间余味

## C 类：内容与准确性

- [ ] 镜号 01–08 没有重复或遗漏，时间码连续且服从用户要求
- [ ] 片名保持用户提供的字形与繁简，不擅自修改
- [ ] 模型生成的微型文字不被错误声称完全可读、印刷级准确
- [ ] 新故事不无意复用参考图的人物、猫、风铃或木廊
- [ ] 避免刻意相似于已有版权动漫人物

## 修复顺序

结构（A+B、3+3+2、上彩下草）→ 工艺（纸张、水彩、手写密度）→ 连续性（人物、道具、情绪）→ 精确文字和时码。

图像模型无法保证所有细节均通过；必须看生成结果再判定，不能以“已出图”替代验收。
