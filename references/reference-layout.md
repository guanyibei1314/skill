## 工艺要点

1. 左侧巨大而松弛的深蓝毛笔标题，不是现代标准无衬线字体。
2. 原创角色的头发细丝、湿润眼睛、柔和衣褶与自然动作；三视图必须是真实不同角度。
3. 背景色彩有湛蓝/淡蓝天空、不同层次植物绿、柔和日照、远景景深及建筑纹理；其他题材迁移画工，不机械保留夏日木屋。
4. 微型手写字、纸边涂鸦、小草图、镜头技术词；避免现代彩色 UI 区块。
5. 红框细线、窄镜号/时码栏、手绘箭头、彩色镜头下附灰草图，每格像真实动画制作记录。
6. 丰富但不杂乱的视觉密度；不能压缩成人物卡片 + 空白方格的通用模板。
