# 《失落的風鈴》原图效果 Skill · v2.0

本 Skill 是**复刻原图视觉效果与版式体系**，不是泛用 storyboard 模板。

## 文件说明

- `SKILL.md`：触发规则与核心流程
- `assets/reference-lost-wind-chime.jpg`：用户选定的《失落的風鈴》**真实原图**，在支持的图像工具中作为风格/构图参考图输入
- `references/reference-layout.md`：原图页面布局测绘
- `references/master-prompt.md`：完整绘图母提示词
- `references/quality-gates.md`：验收标准
- `references/example-lost-wind-chime.md`：原版 8 个节拍
- `assets/brief-template.md`：最简调用模板

## 安装

支持 Agent Skills 的工具：将解压后的 `anime-storyboard-board/` 整个文件夹放入工具的 Skills 目录或通过工具的 Skill 导入流程安装。**不要只上传 SKILL.md 而丢失参考图**。安装/加载成功与否需要在目标工具中验证。

## 最简使用

`按《失落的風鈴》原图效果，做《最后一班电车》：两人在雨后站台重逢；直接生成一张完整动漫开发板。`
